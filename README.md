The last text message a dying phone sends at one percent battery, in the phone's own voice. One message, 75 characters, deterministic: `main.py` writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

> 1%. I held on at 3% for an hour just to watch you panic. Worth it. Goodbye.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py && cat /tmp/out/entry.txt
```
